# LaMoon — Design System (แบบหลัก: Warm Formal)

> แหล่งจริงของดีไซน์ UI แอป LaMoon (ชื่อโปรเจกต์ใน repo: AFOU)
> AI session ไหนจะทำ frontend ให้อ่านไฟล์นี้ก่อน แล้วเปิด `screens/*.html` ดูภาพจริงประกอบ
> Mobile-first (390px) · ภาษา UI = ไทย · Stack: React (JS) + Tailwind + Supabase + Google OAuth

## 1. ภาพรวม

แอปเลือกที่เที่ยวในไทยแบบปัดการ์ด (Tinder-style)
- Flow หลัก: **Landing → Login (Google) → Register/ตั้งค่าโปรไฟล์ (ครั้งแรก) → แผนที่ประเทศไทย → ซูมจังหวัด → เลือกมู้ด → Swipe การ์ด**
- Feel: อบอุ่น ทางการ สะอาด มุมมนเยอะ มีลูกเล่นเล็กๆ (การ์ดเอียง สติกเกอร์พระจันทร์/ดาว) แต่ไม่รก

## 2. หลักการ (สำคัญ)

1. **1 หน้า = 1 ปุ่มหลัก** สีน้ำตาลเข้ม `#5A2E14` ตัวขาว ทรงเม็ดยา (pill) ปุ่มอื่นเป็นพื้นขาว / ข้อความ / ไอคอนเปล่า
2. **ไม่มีขอบดำ ไม่มีเงาหนา ไม่มี gradient** ใช้การวางการ์ดขาวบนพื้นครีมแยกชั้นแทน เงาใช้แค่การ์ดที่ลอย (swipe) แบบจางมาก
3. **มนทุกอย่าง** ไม่มีมุมเหลี่ยม
4. **สีส้ม `#E8793A` เป็นสีเน้น ไม่ใช่สีปุ่ม** ใช้กับ: จังหวัดที่เลือกบนแผนที่, ป้าย "อยากไป", ขอบตัวเลือกที่เลือก, โลโก้พระจันทร์ — ห้ามใช้เป็นสีตัวหนังสือบนพื้นขาว (contrast ไม่ผ่าน)
5. ตัวเลือกที่ "เลือกแล้ว" = พื้นพีช `#F9D9C2` + วงกลมน้ำตาลมีเครื่องหมายถูก (หรือ chip พื้นน้ำตาลตัวขาว)
6. สติกเกอร์ตกแต่ง (พระจันทร์เสี้ยว/ดาว 4 แฉก) วางรอบ hero/การ์ดเท่านั้น `aria-hidden`, กดไม่ได้, ไม่ทับข้อความ

## 3. Color tokens

| Token | Hex | ใช้กับ |
|---|---|---|
| `bg` | `#F5F0EB` | พื้นหลังทุกหน้า, ช่อง input, chip ที่ไม่ได้เลือก |
| `surface` | `#FFFFFF` | การ์ด, แผ่นข้อมูล, ปุ่มรอง, ปุ่มกลับ |
| `peach` | `#F9D9C2` | การ์ดเด่น/hero, ตัวเลือกที่เลือก, พื้นรูปตัวอย่าง |
| `peach-soft` | `#FBE3D2` | วงไอคอน, chip จังหวัดที่เพิ่ม |
| `primary` | `#5A2E14` | ปุ่มหลัก, โลโก้ตัวอักษร, ลิงก์, ป้าย "แนะนำ", หมุดแผนที่ |
| `accent` | `#E8793A` | ไฮไลต์ (ดูข้อ 2.4) |
| `accent-dark` | `#C95F25` | เส้นไอคอนบนพื้นพีช |
| `text` | `#1F1A17` | ตัวหนังสือหลัก |
| `text-2` | `#4A3A30` | ข้อความรอง/คำอธิบาย |
| `muted` | `#6E625A` | caption, label เล็ก, ไอคอนไม่ active |
| `divider` | `#EDE5DD` | เส้นคั่นบาง |
| `success-bg` / `success-text` | `#E7EFDC` / `#3F5A2E` | ป้าย "ตรงมู้ด", ป้ายภาคเหนือ |

**สีภาคบนแผนที่** (เส้นขอบจังหวัดสีขาว 0.9px):
เหนือ `#B9CBA6` · อีสาน `#EDCB8A` · กลาง `#F0BFA6` · ตะวันออก `#E6A57E` · ตะวันตก `#D8C2B0` · ใต้ `#C6D3C9` · จังหวัดที่เลือก `#E8793A` ขอบ `#5A2E14`
ตอนซูม: จังหวัดรอบๆ `#EFE7DF`, จังหวัดที่เลือก `#F9D9C2` ขอบ `#E8793A` 2.5px

**ภาพประกอบ flat:** ภูเขา `#D9A27E` / `#C88A63`, พระอาทิตย์ `#F4A36C`, ใบไม้ `#8BAA6E`

## 5. Shape / spacing

- Radius: ปุ่ม/chip/input/segmented = `999px` · การ์ดใหญ่/แผ่นข้อมูล = `28–36px` · การ์ดเล็ก/รูปในการ์ด = `18–24px` · วงไอคอน/avatar = `50%`
- ระยะขอบจอ 16px (เนื้อหา text 22px) · gap ระหว่างการ์ด 10–14px · ระยะระหว่าง section 28–40px
- Touch target ≥ 44px · ปุ่มหลักสูง 54–56px · ปุ่ม swipe: ข้าม 60px, อยากไป 68px
- เงา: การ์ด swipe `0 6px 18px rgba(90,46,20,.08)` (`#5A2E1414`) — นอกนั้นไม่มีเงา

## 6. Components

- **Header ในแอป** (64px): ปุ่มกลับวงกลมขาว 44px (chevron) · ชื่อหน้า 18/600 มี breadcrumb เล็ก 12px ด้านบน · ขวาสุดเป็น step pill ขาว "1 / 3"
- **ปุ่มหลัก**: `bg primary`, ตัวขาว 16/600, pill, เต็มความกว้าง
- **ปุ่มรอง**: พื้นขาว (หรือขอบ `#D9CFC5` 1.5px บนพื้นครีม), ตัว `text`
- **Chip/filter**: สูง 38–40px, pill · active = พื้น `primary` ตัวขาว · inactive = พื้นขาว (บนพื้นครีม) หรือ `bg` (บนการ์ดขาว)
- **Segmented control** (งบ: ประหยัด/กลางๆ/จัดเต็ม): ราง `bg` padding 4px, ตัวที่เลือกพื้น `primary`
- **Mood tile** (grid 2 คอลัมน์, สูง 108px, radius 24): วงไอคอน 42px + ชื่อ · selected = พื้น `peach` + check วงกลมน้ำตาลมุมขวาบน
- **Search input**: pill สูง 48, พื้นขาว, ไอคอนแว่นขยาย `muted`
- **Swipe card**: การ์ดขาว radius 32 padding 10 → รูป (radius 24, ป้าย "แนะนำ" มุมซ้ายบน) → ชื่อ 24/600 + ป้าย "ตรง x/y มู้ด" + ที่ตั้ง (ไอคอนหมุด) + tag chips
  - **กองการ์ดซ้อนเอียงสลับ**: ใบหลังสุดสีส้มเอียง −7°, ใบกลางสีพีชเอียง +5°, ใบหน้าตั้งตรง
  - ปุ่มด้านล่าง: ข้าม (วงขาว X) · ย้อนการ์ด (ไอคอนเปล่า) · อยากไป (วงน้ำตาล หัวใจขาว ใหญ่สุด)
- **Bottom sheet ข้อมูลจังหวัด**: การ์ดขาว radius 32 ใต้แผนที่ → ชื่อจังหวัด + ป้ายภาค + tag + ปุ่มหลัก "เลือก<จังหวัด>"
- **Logo**: ไอคอนพระจันทร์เสี้ยวสีส้ม + จุดดาวน้ำตาล + คำว่า "LaMoon" 20–22/700 สี `primary`
  SVG: `<path d="M20 14.5A8.5 8.5 0 1 1 9.5 4a7 7 0 0 0 10.5 10.5z" fill="#E8793A"/><circle cx="18.5" cy="5" r="1.5" fill="#5A2E14"/>` (viewBox 0 0 24 24)
- **สติกเกอร์**: พระจันทร์ (path เดียวกับโลโก้) · ดาว 4 แฉก `M12 2l2 7 7 2-7 2-2 7-2-7-7-2 7-2z` · สี `accent`/`primary`/`peach`/`#F4A36C`, ขนาด 12–40px, หมุน ±10–20°
- **ไอคอน**: เส้นแบบ Lucide, stroke 1.8–2.2, round caps

## 7. หน้าจอ (ดูภาพจริงใน `screens/`)

| ไฟล์ | หน้า | จุดสำคัญ |
|---|---|---|
| `01-landing.html` | Landing ก่อน login | hero "ปัดการ์ด เจอที่เที่ยวที่ใช่" + การ์ดเรียงพัด 3 ใบ (ซ้ายเอียง "ข้าม", ขวาเอียง "อยากไป") + 3 ขั้นตอน + แผนที่ย่อ + การ์ดตัวอย่าง + CTA น้ำตาล + footer · ไม่มี bottom nav |
| `02-login.html` | Login | Google อย่างเดียว ปุ่มเดียว (สมัครใหม่ใช้ปุ่มเดียวกัน) |
| `03-register.html` | ตั้งค่าโปรไฟล์ครั้งแรก | ชื่อที่แสดง (ดึงจาก Google) · มู้ดที่ชอบ (หลายอัน) · ภาค/จังหวัด (ไม่บังคับ) · checkbox ยอมรับข้อตกลง (บังคับก่อนกด "เริ่มใช้งาน") |
| `04-map.html` | แผนที่ทั้งประเทศ (ขั้น 1/3) | ค้นหาจังหวัด · filter ภาค · แผนที่ 77 จังหวัดสีตามภาค · ปุ่มสุ่มจังหวัด |
| `05-map-zoom.html` | ซูมจังหวัด | จังหวัดเต็มกรอบ + หมุดที่เที่ยว · ปุ่ม +/− · "ดูทั้งประเทศ" · bottom sheet + ปุ่ม "เลือก<จังหวัด>" |
| `06-mood.html` | เลือกมู้ด (ขั้น 2/3) | grid มู้ด สูงสุด 3 · segmented งบต่อคน |
| `07-swipe.html` | Swipe (ขั้น 3/3) | กองการ์ดเอียงสลับ + สติกเกอร์ · 3 ปุ่มล่าง |

ลิงก์ระหว่างไฟล์กดได้ เปิด `01-landing.html` ใน browser แล้วไล่ flow ได้เลย

## 8. ข้อมูลแผนที่

เส้นขอบจังหวัดมาจาก GeoJSON สาธารณะ https://github.com/apisit/thailand.json (projection equirectangular, ปรับ lon × cos 13°, ลดรายละเอียดด้วย Douglas–Peucker) · ตอนทำจริงแนะนำโหลด GeoJSON แล้ว render ด้วย SVG/`d3-geo` แทนการ hardcode path
